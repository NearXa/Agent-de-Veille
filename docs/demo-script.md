# Script de démonstration (8 minutes)

Public : jury de l'atelier. Matériel : terminal à la racine du dépôt (`.env` renseigné), navigateur sur
http://localhost:8501, page Notion « GRC EPITA » ouverte dans un second onglet.

| Min  | Séquence                 | Ce que l'on montre                                                                                                                                                                                                                                                                | Commande ou action                                                                                                                                                                       |
| ---- | ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0:00 | Le problème              | Veille documentaire manuelle, textes longs (DORA : 64 articles, 106 considérants), obligations dispersées, besoin d'une traçabilité vérifiable et d'une décision humaine                                                                                                          | diapositive 1 de `docs/presentation.md`                                                                                                                                                  |
| 0:45 | L'architecture           | Sources → connecteurs → ingestion → pipeline AI SDK + Zod → store JSON → matrices et gouvernance → Notion (6 bases, MCP) → cockpit                                                                                                                                                | schéma de `docs/architecture.md`                                                                                                                                                         |
| 1:30 | Étape 1 : charger        | `TX-0001` avec titre, référence CELEX, URL officielle, hash, 64 articles segmentés                                                                                                                                                                                                | `pnpm agent ingest --file data/sources/dora-32022R2554-fr.html --source eurlex --ref CELEX:32022R2554 --url "https://eur-lex.europa.eu/legal-content/FR/TXT/HTML/?uri=CELEX:32022R2554"` |
| 2:15 | Étapes 2 et 3 : extraire | 3 chunks, 85 exigences, 85 vérifiées dans la source (verbatim + article), coût et tokens journalisés ; en direct avec le cache (0 $)                                                                                                                                              | `pnpm agent extract --texte TX-0001 --articles 5-16` puis ouvrir `data/store/exigences.json` sur `EX-0004`                                                                               |
| 3:15 | Étape 4 : matrice M1     | `output/matrices/M1-tracabilite.csv` et `.md`, pied de page (run, % vérifiées)                                                                                                                                                                                                    | `pnpm agent matrices --texte TX-0001 --only M1 --format csv,md`                                                                                                                          |
| 3:45 | Étape 5 : Notion         | 6 bases reliées sous « GRC EPITA », pages Textes et Exigences « À valider », relations ; `init` idempotent                                                                                                                                                                        | `pnpm notion init && pnpm notion push` (ou montrer le résultat déjà en place)                                                                                                            |
| 4:30 | Étape 6 : valider        | Vue « Validation humaine » : file triée par confiance, panneau de détail (verbatim, lien vers l'article, trois composantes de la confiance), bouton Valider → page Notion mise à jour + commentaire d'audit, exigence suivante                                                    | `pnpm cockpit`, renseigner « Validateur », valider `EX-0004` ; rafraîchir Notion                                                                                                         |
| 5:30 | Analyse complète         | Applicabilité « Oui » (0,95), enrichissement (échéance 17/01/2025 via art. 64, sanctions art. 50 à 54), impact, couverture (5 / 71 / 9), 80 risques résiduels, M1 à M5 et classeur XLSX ; 28 appels, 2,91 $, 15 min, rejoué en 36 s avec le cache                                 | `pnpm agent run --texte TX-0001 --articles 5-16 --max-cost 12` (cache) puis vue « Textes et matrices » : onglets M1 à M5, graphiques                                                     |
| 6:30 | Gouvernance              | Recommandation **Hybride** (TOGAF 55 / ITIL 65), 14 lots d'action priorisés, plan avec RACI et indicateurs, 9 points de décision humaine ; décision prise dans le cockpit et écrite dans Notion + `decision.json`                                                                 | vue « Pilotage » : KPI, échéances, lots, bloc de décision ; `docs/plan-gouvernance.md`                                                                                                   |
| 7:15 | Veille continue et MCP   | Passage de veille sur EUR-Lex (Cellar), AN, Sénat, CNIL, CERT-FR ; diff par article et « À revalider » ; question en langage naturel sur les bases Notion                                                                                                                         | `pnpm agent watch --once --source cnil,senat` ; `pnpm agent ask "Quelles exigences ont un risque résiduel critique ?"`                                                                   |
| 7:45 | Limites et suite         | Hallucination maîtrisée par la vérification par code mais interprétation juridique non substituable à un juriste ; PISTE non exercé ; applicabilité fine par catégorie d'entité à valider ; pistes : Légifrance / Judilibre en réel, corpus de jurisprudence, planification cloud | `docs/resultats-et-limites.md`                                                                                                                                                           |

Plan B sans réseau : `pnpm agent demo --skip-notion` (cache LLM) et `pnpm cockpit` en lecture seule sur `data/store/`.
